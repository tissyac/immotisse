Informations de base pour l'hébergement (version localhost)

1. Structure du projet
- Frontend React : client/
- Backend Node/Express : server/
- Base de données : MongoDB
- Stockage de fichiers : Cloudinary pour les images/vidéos

2. Commandes principales
- Installer les dépendances backend : npm install
- Lancer le backend local : npm run dev (ou node server/server.js selon le projet)
- Installer les dépendances frontend : cd client && npm install
- Lancer le frontend local : npm run dev

5. Routes importantes backend
- Route de signature Cloudinary : GET /cloudinary/sign?resourceType=image
- Route de signature Cloudinary pour vidéo : GET /cloudinary/sign?resourceType=video
- Route de vérification du token : GET /auth/verify
- Route de statut API : GET /api/status

6. Notes importantes
- Le frontend utilise `VITE_API_URL` pour appeler le backend.
- La signature Cloudinary est générée côté backend, puis l’upload se fait directement depuis le navigateur vers Cloudinary.
- Pour les vidéos, le backend doit accepter `resourceType=video` et la configuration Cloudinary doit être présente.
- En local, `VITE_API_URL` doit pointer vers l’URL du backend local (http://localhost:3008).
